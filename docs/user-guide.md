# Agent Dock 用户使用说明

## 1. 安装与打开

1. 下载 `Agent-Dock-<版本>-arm64.dmg`。
2. 打开 DMG，把 Agent Dock 拖入“应用程序”。
3. 首次启动若被系统阻止，进入“系统设置 → 隐私与安全性”，点击“仍要打开”。
4. 点击屏幕顶部刘海区域，或按默认快捷键 `Space` 展开工作台。

退出应用：打开“设置”，点击底部醒目的“退出 Agent Dock”；也可以使用菜单栏图标中的退出项。

## 2. 工作台模块

| 模块 | 用途 | 常用操作 |
| --- | --- | --- |
| 运行状态 | 显示 Agent 当前在运行、等待或可能过期的任务 | 点击条目打开对应 Agent |
| 待我处理 | 汇总需要确认、失败、过期和临近截止事项 | 点击 Agent 条目打开应用；点击本地任务进入任务页 |
| 已完成 | 保存最近的完成与失败摘要 | 打开、复制摘要、选择分类后转任务 |
| 快速交代 | 临时整理要交给 AI 的文字 | 选择目标 AI，复制并打开；也可转任务或存草稿 |
| 番茄钟 | 本地专注计时 | 设置时长，开始、暂停或重置 |
| 会话便笺 | 记录当前项目和下一步 | 关联 Agent/项目并保存到草稿 |

卡片可长按拖动。拖动右下角斜线手柄可按 12 × 4 网格拉宽、拉窄、拉高或拉低；松手后自动吸附并重排。键盘聚焦手柄后，也可用方向键逐格调整。

## 3. 接入 Agent

1. 打开“设置 → Agent 来源”。
2. 在 Codex、Claude Code、WorkBuddy 或 Gemini CLI 旁点击“复制配置”。
3. 按 [Agent Hook 安装说明](agent-hook-installation.md)合并配置。
4. 重启对应 AI 工具并新建任务。

接入成功后的状态流转：

```text
开始任务 → 运行状态
需要你确认 → 待我处理
任务结束 → 已完成
```

不同来源支持的状态可能不同。Agent Dock 只展示发送端明确上报的状态，不会把长时间无事件自动判定为失败。

## 4. 打开、复制与转任务

- **打开**：优先根据项目名与窗口标题定位。无法精确定位 Codex 对话时，会打开最近使用的 ChatGPT/Codex 窗口并显示提示。
- **复制**：只复制清洗后的摘要，不复制完整对话。
- **转任务**：选择任务分类后创建本地任务，默认截止时间为当天 23:30。

这些操作只在用户点击后执行。

## 5. 任务与笔记

- “任务”页提供四个可改名分类，支持截止时间、完成、编辑与删除。
- “笔记”页保存会话便笺，可搜索、改名和继续编辑。
- “快速交代”中的文字默认不保存；只有点击“存草稿”或“转任务”后才会持久化。

## 6. 语音与可选能力

进入“语音”页并主动开始录音后，应用才会请求麦克风权限。实时转写与智能命名是可选能力，需要在设置中自行配置服务。

剪贴板面板默认关闭，可在设置中启用。开启后只处理本机剪贴板历史。

## 7. 桌面小猫

小猫会沿工作台面板边缘巡逻，并根据状态睡觉、探头、庆祝或荡秋千。所有状态统一为 48px 高。开启 macOS“减少动态效果”后，持续移动会停止。

可在“设置 → 桌面伙伴”关闭小猫。

## 8. 数据与隐私

默认数据目录：

```text
~/Library/Application Support/Agent Dock
```

主要文件：

- `workspace.json`：任务、笔记与本地索引。
- `agent-runs.json`：来源、运行 ID、状态、标题、项目、摘要与时间。
- `recordings/`、`clipboard-images/`：用户主动产生的本地素材。

Agent Dock 不保存完整 Prompt、完整输出、代码、工具参数或绝对工作目录。事件服务只监听本机回环地址。

## 9. 导入旧数据

在“设置 → 从 TO-DO Panel 导入”中主动选择旧数据目录。只导入待办、分类名、笔记、录音、剪贴板素材及相关文件；不会导入链接、旧常用指令、密码、API Key、应用设置、系统权限或镜子图片。

导入按 ID 去重，可安全重试，不会覆盖 Agent Dock 中已有内容。

## 10. 常见问题

### 左上角“运行状态”没有内容

先确认 Agent Dock 已启动，再检查对应 Agent Hook 是否已合并并信任。可在终端运行：

```bash
curl http://127.0.0.1:43822/health
```

返回包含 `"ok": true` 表示本机事件服务正常。

### 点击“打开”提示未找到窗口

先打开对应 Agent 应用。Agent Dock 会尝试匹配项目名和窗口标题；如果来源没有提供足够信息，只能打开最近使用的应用窗口，不能保证定位到具体对话。

### 看不到顶部菜单栏图标

菜单栏空间不足时，macOS 可能隐藏图标。仍可通过刘海区域或快捷键展开，并在设置页退出应用。

### 设置页无法滚动

将鼠标移到需要查看的设置列内，再使用触控板或鼠标滚轮。窗口高度不足时，设置列会独立滚动。
